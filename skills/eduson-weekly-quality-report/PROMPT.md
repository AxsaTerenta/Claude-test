# Промт для нового чата: недельный отчёт ОКК по группе

Скопировать целиком, подставить значения в фигурных скобках, приложить или указать пути к выгрузкам.

---

Собери недельный отчёт по качеству переговоров по команде **{имя руководителя группы}** за период **{ГГГГ-ММ-ДД — ГГГГ-ММ-ДД}** строго по скиллу `skills/eduson-weekly-quality-report/SKILL.md`.

Входные данные:
- выгрузка звонков за неделю: `{путь к txt}`;
- выгрузка метрик по менеджерам: `{путь к json или содержимое}`;
- логотип для страницы: `eduson-design-book/eduson-logo.png`.

Порядок работы — как в §4 скилла, без отклонений:

1. Собери `config.json` по §5: команда, период, префикс ссылок `https://eduson.amocrm.ru/leads/detail/`, названия колонок выгрузки метрик, пороги без изменений.
2. Прогони `pipeline/build_data.py` и прочитай `data.json`: числа, метки, доли этапов, список менеджеров под разбор «ниже среднего».
3. Прочитай резюме всех разобранных сделок и транскрипты тех, на которые будешь ссылаться. Отбери дословные цитаты: сильные приёмы и места потери сделки. Цитату с темой из стоп-листа §9 не бери.
4. Определи записи контакт-центра по §7.2 и перечисли их номера в `contact_center_calls`. В тексте отчёта про них не пиши.
5. Проверь автоматические категории A/B/C по резюме и выпиши исключения в `category_overrides` (в примере недели их было 21 из 98).
6. Напиши `content.json` по §6: выводы недели, расхождения балла и результата, разборы «почему ниже среднего», паттерны, единичные наблюдения, приоритеты, лучшие практики, планы развития на каждого менеджера.
7. Прогони `render_report.py`, `render_html.py`, `verify.py`. Провал проверки — исправь и перегенерируй.
8. Опубликуй по §11.2: `reports/{ГГГГ-ММ-ДД_ГГГГ-ММ-ДД}/` с пятью файлами, коммит только этой папки, push, дай ссылку на страницу.

Требования к языку — §3 скилла: клиенты вместо лидов, выручка вместо денег, среднее по группе вместо базы; запрещены транзакционная, дуга, скоринг, кластер, инверсия, критический кейс, латиница вне названий продуктов. Каждый пункт — законченное предложение с подлежащим и сказуемым. Конструкция вывода: наблюдение → следствие для выручки → управленческое действие.

Отчёт обязан совпасть с образцом `reports/2026-07-20_2026-07-26/` по составу разделов, порядку, оформлению и манере формулировок. Отличаются только числа, тексты и имена.

В конце пришли: ссылку на страницу, объём выборки, метки менеджеров, список системных паттернов с числом сделок и перечень тех, кому собран разбор «ниже среднего».

## Короткая версия, если нужен только пересбор после правок текста

Перегенерируй отчёт `{период}`: обнови `content.json`, прогони `render_report.py`, `render_html.py`, `verify.py`, скопируй в `reports/{период}/`, закоммить и запушь. Ничего в оформлении и порядке разделов не меняй.
